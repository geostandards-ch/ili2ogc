ch_swisstopo_CHENyx06_ETRS.tif - CHENyx06 distortion grid (CH1903+ / LV95 to ETRS89), GeoTIFF converted from the
swisstopo NTv2 file by the PROJ-data project (https://github.com/OSGeo/PROJ-data, directory ch_swisstopo).
Licence: Creative Commons CC0 1.0 Universal. Credit: (c) 2007 swisstopo.
Used by interlis/convert/wgs84.py to reproject the WGS 84 fallback geometry of a JSON-FG place from LV95
without network access (the Helmert transformation PROJ falls back to is off by up to about a metre).
